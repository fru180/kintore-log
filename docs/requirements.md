# 筋トレログ

## 概要
筋トレの記録を行うWebアプリ
スマートフォンで利用することを前提とするが、PCからも閲覧可能
個人的に利用するアプリのためセキュリティや可用性などの要件は最小限に抑えて開発を高速化する
Cloudflare workersにデプロイを行い、D1にデータを保存する

## 機能
### 筋トレ記録
アカウント名・パスワードによるログイン機能を有す。複数ユーザーに対応する
初期管理者アカウントは手動登録し、既存アカウントをDBで直接編集して管理者に昇格させる
１日ごとに筋トレの記録を行うことができる
- 筋トレ種目×重量×回数×セット数を記録できる
- アシスト機種の補助重量は負数で記録できる
  - 同一日に同一種目を記録できるのは1回までとする
  - 記録の編集・削除ができる
１ページに筋トレ種目１行１種目が並んでいて記録ボタン押下で記録
重量、回数、セット数のデフォルト値は（0kg、10回、３セット）
重量はユーザ・種目ごとの全期間の最新記録をAPIから一括取得し、次回のデフォルトとして表示する。記録がない種目は0kgとする
回数・セット数・距離・時間を変更した場合はlocalStorageに保存し、次回以降はそれをデフォルト表示とする
筋力種目名の右に重量アップ候補を示す炎アイコンを表示する。通常はグレー、選択時は赤とし、ラベルは表示しない。
候補状態はユーザー・種目ごとに保存し、日付や記録の保存状態にかかわらず、再度アイコンを押して解除するまで維持する。有酸素種目には表示しない
カレンダー表示で筋トレ実施日の記録を確認可能
ランニング、水泳も種目として表示しておき、距離（km）・時間（分）を設定できるようにする
体重（kg）の入力欄を種目入力一覧の最下部に設ける

体重入力欄の下に「鍛えた部位」を表示する。当日に保存済みの種目から対象筋肉を自動集計し、
横方向へ360度回転でき、ホイール・ピンチ・画面上のボタンで拡大縮小できる精密な3D解剖モデル上で対象部位を着色する。
拡大中は人体図をドラッグして表示領域を上下左右へ移動でき、リセット操作で正面・等倍・中央位置へ戻せるものとする。
人体図上の主要な筋肉をタップまたはクリックすると、筋肉名とその筋肉に対応する登録種目を下部シートで表示する。
「鍛えた部位」には当日に鍛えた筋肉と、対象筋群のうち鍛えられていない筋肉を分けて一覧表示する。
どちらの一覧も筋肉名をタップまたはクリックすると、人体図上の該当部位を強調表示する。
下部シートの表示中も背景を暗転させず、通常画面のスクロールやボタン操作を可能とする。
対象は一般的な筋力トレーニングで扱う主要筋群に限定し、細かな表情筋・眼筋・手指筋などは選択対象外とする。
対応表に登録種目がない主要筋群には「対応種目なし」と表示する。
通常の筋肉は暗赤色、対象部位はライム色とする。
モデルはZ-Anatomy / BodyParts3D由来のCC BY-SA 4.0素材を使用し、画面上に帰属とライセンスを表示する。
重量・回数・セット数は判定に使わず、
未保存の入力や対応表にない種目は着色しない。

種目と筋肉の対応は以下の通りとする。

- レッグプレス：大腿四頭筋、ハムストリング、大臀筋
- チェストプレス：大胸筋、三角筋、上腕三頭筋
- ラットプルダウン：僧帽筋、大円筋、広背筋
- シーテッドロー：上腕二頭筋、広背筋上部、広背筋
- ロングプル：広背筋下部、上腕二頭筋
- ショルダープレス：三角筋、僧帽筋、上腕三頭筋
- ラインレッグカール：ハムストリング、腓腹筋
- レッグエクステンション：大腿四頭筋
- ヒップアブダクター：内転筋、外転筋
- ヒップアダクター：内転筋
- カーフレイズ：腓腹筋、ヒラメ筋
- バックエクステンション：脊柱起立筋
- アブドミナルクランチ：腹直筋
- ロータリートルソー：内腹斜筋、外腹斜筋
- リアデルト：三角筋後部
- バタフライ：大胸筋

チンニングは着色対象なしとする。

### グラフ
- 筋トレの種目ごとの、その日に記録したセット重量の推移グラフ
- 体重推移

### タイマー
筋トレに利用できるカウントアップタイマーをセットできる
時間は3分・10分・無制限から選択でき、1分おきに音を鳴らす
画面オフ・バックグラウンド時も音を鳴らすことを目標とする。ただし、実現可否と動作範囲はブラウザおよびOSのバックグラウンド実行・音声再生の制約に従う

### 管理者機能
筋トレ種目の追加編集削除、並び順の編集が可能

## 画面構成
初期画面はログイン画面
ログインすると筋トレ記録画面に遷移
フッターでグラフ画面-記録画面を遷移
タイマーはグラフ画面の右下にボタンをフロートさせておき、押すとモーダルが開いてタイマー設定可能

## 技術要件
frontend: React
backend: JavaScript（Cloudflare Workers）
DB: cloudflare d1

github actionsでデプロイまでする
