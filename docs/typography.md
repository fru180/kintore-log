# フォントサイズのポリシー

記録ページの文字サイズと情報密度を基準にする。通常の見出しは18〜20pxに抑え、階層は文字の太さと余白でも表現する。PCとスマートフォンで標準サイズを共通にし、画面幅に応じて見出しを拡大しない。

## 標準サイズ

`src/styles.css` の `:root` にある用途別変数を使う。

| 用途                                     | CSS変数                        | サイズ |
| ---------------------------------------- | ------------------------------ | ------ |
| ページ・モーダル見出し                   | `--font-size-heading`          | 20px   |
| カード・セクション見出し                 | `--font-size-section`          | 18px   |
| 種目名などの項目見出し                   | `--font-size-item`             | 15px   |
| 入力欄                                   | `--font-size-input`            | 16px   |
| 本文・通常ボタン・選択切替               | `--font-size-body`             | 13px   |
| 大きな操作ボタン                         | `--font-size-button-prominent` | 14px   |
| 通知・空状態の説明                       | `--font-size-status`           | 12px   |
| 補足説明・フォームラベル・ナビゲーション | `--font-size-support`          | 11px   |
| 小さな補助見出し・凡例                   | `--font-size-caption`          | 10px   |
| 単位・バッジ・短い補助ラベル             | `--font-size-detail`           | 9px    |
| 省スペースの単位・補助数値・出典         | `--font-size-micro`            | 8px    |

ページ見出しの行高は1.4とする。本文や説明は折り返したときも読める行高を確保する。8〜10pxは補助情報用で、主要な見出し・操作・入力には使わない。見出しのHTMLレベルは文書構造に合わせ、文字サイズは表示上の役割で選ぶ。

## 維持する例外

- 記録ページ本体、そこから開くカレンダー、筋肉の詳細表示は、各画面幅で既存の文字サイズを維持する。日付入力やカレンダーの日付は従来の継承サイズを使い、全体の基準サイズは変更しない。
- カレンダーの年月見出しは25px。筋肉の詳細シート見出しは28px、種目の筋肉モーダル見出しはPCで30px、540px以下で27px。関連表示の現状を維持するための例外とする。
- ブランド名は通常17px、認証画面19px。ロゴとしての表示を維持する。
- タイマーの時間表示は66px、540px以下で56px。時間を素早く確認できる大きさを維持する。起動ボタン・プリセットの文字サイズも現状を維持する。
- グラフの強調数値は36px。SVG内の軸ラベル14、ツールチップの値15・日付11はviewBox上の座標単位であり、表示倍率の影響を受けるため現状を維持する。
- 記録入力の掛け算記号は18px、筋肉一覧の小見出しは13pxなど、記録ページの既存の役割分けを維持する。

## 新しい画面・変更時のルール

新規UIでは標準の用途別変数を使用する。数値を直接指定する例外が必要な場合は、その用途と理由をこの文書に追加する。変数を変更すると既存画面にも影響するため、記録ページのサイズを変える目的がない限り標準値は変更しない。

文字サイズの変更に合わせてボタンや入力欄の高さ・操作領域を縮めない。PCとスマートフォンで、長い日本語の折り返し、はみ出し、入力欄の表示を確認する。記録ページと関連表示は変更前後のサイズを比較する。
